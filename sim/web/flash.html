Install CYD Palm on your board

CYD Palm is a Palm-style organiser for the ESP32 "Cheap Yellow Display". It syncs its Date Book, To Do and Address apps with iCloud. This page writes it onto your board over USB. You don't need to install any tools.

What you need

  • An ESP32-2432S028R, the base CYD without PSRAM, with 4 MB of flash.
  • A USB cable that carries data, not just power.
  • A microSD card. Your records are stored on it.
  • Chrome, Edge or Chromium on a computer. The page talks to the board over Web Serial, which Firefox, Safari and phones don't have.
This browser can't talk to a USB device. Open this page in Chrome or Edge on a computer. Web Serial needs a secure page. Open this over https.

Installing

  1. Plug the board in and press Install. Then choose the port. On most boards it's named USB-SERIAL CH340.
  2. The installer asks whether to erase the device. The answer depends on what is on the board now, not on whether you've used this page before.
    • CYD Palm is already on it, however it got there: leave the box clear. Erasing wipes your saved Wi-Fi and account passwords, the clock and the touch calibration, and you'd have to set them up again. Your records are on the microSD card, so they're safe either way.
    • Anything else, such as the factory demo: tick the box.
  3. The install takes about a minute. The board restarts when it's done. If the screen stays dark, press the RST button on the back.

After it starts

The first time it starts, the board asks you to calibrate the touch screen, so that a tap lands where you touched. It shows three white crosshairs, one at a time, in the corners. Tap the centre of each one with a stylus or a fingernail. The board remembers the result. If taps ever land in the wrong place, hold a finger on the screen while the board starts and it will ask again. It also asks again after an install with erase ticked.

Put the microSD card in. The first time it starts, the device adds a few sample records so the apps aren't empty. Open Settings and set up Wi-Fi, then Accounts. Accounts needs your Apple ID and an app-specific password, which you create at appleid.apple.com under Sign-In & Security. Then run a HotSync.

If the port doesn't appear

  • Try another cable. Many USB cables only carry power.
  • Windows and macOS may need the CH340 USB driver from WCH, the company that makes the board's USB chip.
  • On Linux, a browser installed as a Snap (the Ubuntu App Center's Chromium, for example) can't see USB ports until you allow it. Run sudo snap connect chromium:raw-usb, then restart the browser.

If it says "Failed to initialize"

The installer couldn't switch the board into its flashing mode by itself. This is common with the CH340 chip. Do it by hand instead:

  1. Reload this page.
  2. On the back of the board, hold BOOT. Press and release RST, then let go of BOOT. The screen stays dark while the board waits.
  3. Press Install and pick the port again.
  4. When it's done, press RST to start CYD Palm.
